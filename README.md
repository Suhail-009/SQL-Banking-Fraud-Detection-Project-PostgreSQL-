**SQL-Banking-Fraud-Detection-Project (PostgreSQL)**

A complete end-to-end SQL project using PostgreSQL on a synthetic banking transactions dataset (500 records). This project showcases fraud detection, customer analytics, merchant insights, window functions, and advanced SQL techniques for portfolio and resume use.

**📊 Project Overview**

This project analyzes financial transaction data to detect potential fraudulent activity, identify high-value customers, and generate business insights.

Dataset fields include:

* transaction_id
* customer_id
* transaction_date
* transaction_time
* amount
* transaction_type (debit/credit)
* merchant
* status (success/failed)
* device_type
* location

**🛠️ Technologies Used**

* PostgreSQL
* SQL Window Functions
* CTEs (Common Table Expressions)
* Aggregations and Joins
* Time-series functions
* Fraud rule-based logic

✔ Used PostgreSQL window functions for advanced analytics
